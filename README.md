# Kursus Online – Laravel 8

Proyek ini merupakan pengembangan sistem informasi **kursus privat online** berbasis Laravel 8.  
Dibuat sebagai tugas kuliah semester 4 dan sekaligus digunakan sebagai portofolio pribadi.

---

## ✨ Fitur Utama

- Menampilkan informasi kursus privat
- Pendaftaran kursus melalui form dan integrasi WhatsApp
- Manajemen data mentor, jadwal kursus, dan pembayaran siswa (via admin panel)

## ⚙️ Cara Install Singkat

1. Clone/download project  
2. Buat database `comprolaravel8`, lalu import `db/comprolaravel8.sql`  
3. Rename `.env.example` menjadi `.env` dan sesuaikan konfigurasi database  
4. Jalankan: `php artisan key:generate`  
5. Akses via browser: `http://localhost/comprolaravel8`

---

## 🛠️ Minimum Server Requirement

- PHP 7.3 atau lebih tinggi  
- Ekstensi: BCMath, PDO, Mbstring, OpenSSL, XML, dsb
